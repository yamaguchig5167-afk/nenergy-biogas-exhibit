# 食品ごみが、電気になるまで。

エヌエナジー株式会社（熊本西部バイオガス発電所）のバイオガス発電のしくみを、タッチして学ぶ展示コンテンツです。
2026年11月21日〜22日「UT WONDER LAND 2026」（グランメッセ熊本）で、MAXHUB の大型タッチディスプレイに表示します。

- 展示モード（会場用・自動再生と待機画面）：`index.html#kiosk`
- 実機の自己診断（設営の確認用）：`index.html#kiosk-check`
- Web版：`index.html`
- 子ども向け「もっとリサイクル！わけわけチャレンジ」（永野商店 × エヌエナジー）：`recycle.html`（会場用は `recycle.html#kiosk`。90秒さわらないとバイオガスの展示に戻る）
- スマホ用「おうちミッション」：`mission.html`（めいじんカードの QR から。`?s=ほし&f=つまずいた所`。チェックはスマホの中だけに残り、何も送信しません）

単一のHTMLファイルで、外部の読み込みはありません（説明欄の動画もファイルに埋め込み）。エヌエナジー様の紹介動画（YouTube）：https://www.youtube.com/watch?v=RRz87myyzbQ

来場者の手書きは保存・送信しません。

展示システム制作：ソルエイト株式会社

## お知らせの出し方（展示モードの画面上部に出る）

`notice.json` の `text` に40文字以内で書いて保存（GitHub の画面で鉛筆ボタン → Commit）。2分以内に、通信につながっている MAXHUB に出ます。消すときは `""` に戻します。

```json
{ "text": "14:00から ステージで発表します", "from": "2026-11-21T13:30", "to": "2026-11-21T14:30" }
```

`from`・`to` は空でもかまいません（空ならずっと出ます）。

## そのほかのファイル

- `cert.html`：はかせ認定証をスマホで作るページ（展示画面の QR から開く。なまえも画像も送信しない）
- `sw.js`：一度開くと手元に保存し、通信が切れても展示が続くようにするしくみ
- `media/intro_720p.mp4`：紹介動画の全編（エヌエナジー公式 YouTube より。通信があるときだけ展示画面で再生）
